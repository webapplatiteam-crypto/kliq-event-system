# KLIQ Experience — คู่มือขึ้นระบบจริง

ระบบลงทะเบียน + สุ่มการ์ด KLIQ + Passport 6 ฐาน + จุดรับของที่ระลึก + รอบชิงบนเวที + หลังบ้านแอดมิน · ฐานข้อมูล Supabase · เว็บบน Netlify (หรือ Vercel)
รองรับ 400 คน (ปรับได้ในหน้าตั้งค่า) · เว็บล้วน ไม่ต้องติดตั้งแอป · ใช้ Supabase (ฐานข้อมูล) + Netlify (หน้าเว็บ)

ใช้เวลาขึ้นระบบประมาณ 20 นาที

---

## สิ่งที่อยู่ในโฟลเดอร์นี้

| โฟลเดอร์ / ไฟล์ | คืออะไร |
|---|---|
| `supabase/schema.sql` | ตาราง + ฟังก์ชันทั้งหมดของระบบ (รันครั้งแรกครั้งเดียว) |
| `supabase/seed.sql` | ข้อมูลเริ่มต้น: 5 การ์ดซีรีส์ 6 ฐาน รางวัลรอบชิงที่ 1–3 และบัญชีแอดมินคนแรก |
| `supabase/reset_event_data.sql` | ล้างข้อมูลผู้ร่วมงานหลังซ้อม หรือหลังจบงาน |
| `web/` | หน้าเว็บทั้งหมด ลากวางขึ้น Netlify |
| `web/config.js` | ไฟล์เดียวที่ต้องแก้: ใส่ที่อยู่และคีย์ Supabase |
| `tests/` | สคริปต์ทดสอบที่ใช้ตรวจระบบ (ไม่ต้องอัปโหลด) |

## ขั้นตอนที่ 1 · สร้างฐานข้อมูลบน Supabase

1. สมัคร/เข้าสู่ระบบที่ **supabase.com** → **New project**
   - Region: **Southeast Asia (Singapore)** (ใกล้ไทยที่สุด)
   - ตั้งรหัสผ่านฐานข้อมูลและจดเก็บไว้
2. แนะนำอัปเกรดเป็นแผน **Pro** ก่อนวันงานอย่างน้อย 1 สัปดาห์ (แผนฟรีจะหยุดโปรเจกต์อัตโนมัติถ้าไม่มีคนใช้ 7 วัน และไม่มีสำรองข้อมูลรายวัน)
3. ไปที่เมนู **SQL Editor** → **New query**
   - เปิดไฟล์ `supabase/schema.sql` คัดลอกทั้งหมดไปวาง → กด **Run** (ต้องขึ้น Success)
   - (ถ้าเคยรัน schema รุ่นก่อนแล้ว รัน `schema.sql` ใหม่ทับได้เลย ข้อมูลเดิมไม่หาย แล้วตั้งรางวัลอันดับ 1–3 ในหลังบ้าน)
   - เปิดไฟล์ `supabase/seed.sql` **แก้บรรทัด `v_admin_pin` เป็นตัวเลข 6 หลักของคุณ** แล้ววาง → กด **Run**
     (ถ้าลืมแก้ ระบบจะแจ้งเตือนให้แก้ก่อน)

## ขั้นตอนที่ 2 · เอาคีย์มาใส่ในเว็บ

1. ใน Supabase ไปที่ **Project Settings → API** (หรือ **Data API / API Keys**)
2. คัดลอก 2 ค่า:
   - **Project URL** เช่น `https://abcd1234.supabase.co`
   - **anon public key** (หรือ Publishable key) — คีย์นี้เป็นคีย์สาธารณะ ใส่ในเว็บได้
   - ⚠️ ห้ามใช้ **service_role / secret key** ในเว็บเด็ดขาด
3. เปิดไฟล์ `web/config.js` แล้วแทนค่า `YOUR-PROJECT` และ `YOUR-ANON-KEY`

## ขั้นตอนที่ 3 · ขึ้นหน้าเว็บบน Netlify (ฟรี ไม่ต้องใช้คำสั่ง)

1. สมัคร/เข้าสู่ระบบที่ **app.netlify.com** (ใช้อีเมลหรือ GitHub)
2. เปิด **app.netlify.com/drop** → **ลากโฟลเดอร์ `web` ทั้งโฟลเดอร์** (ที่แก้ `config.js` แล้ว) ไปวางในหน้าเว็บ → รอ ~30 วินาที
3. ได้ลิงก์ชั่วคราวแบบ `https://ชื่อสุ่ม.netlify.app` → ไปที่ **Site configuration → Site details → Change site name** ตั้งเป็นเช่น `kliq-experience` จะได้ `https://kliq-experience.netlify.app`
4. **โดเมนของตัวเอง (แนะนำ):** **Domain management → Add a domain** ใส่เช่น `event.kliq.co.th` แล้วไปตั้ง DNS ที่ผู้ให้บริการโดเมนตามที่ Netlify บอก (CNAME ชี้ไป `ชื่อไซต์.netlify.app`) · HTTPS ออกให้อัตโนมัติภายในไม่กี่นาที
   **ทำก่อนพิมพ์ QR** เพราะ QR ทุกใบผูกกับโดเมน
5. **อัปเดตเว็บภายหลัง** (เช่น แก้ privacy.html): เข้า **Deploys** → ลากโฟลเดอร์ `web` ไปวางที่กรอบ "Drag and drop your site output folder here" อีกครั้ง — ของเดิมถูกแทนที่ ลิงก์เดิมไม่เปลี่ยน

ในโฟลเดอร์ `web` มีไฟล์ `_headers`, `_redirects`, `netlify.toml` อยู่แล้ว (ตั้งค่าแคชและความปลอดภัย) ไม่ต้องแก้อะไร · ถ้าจะใช้ Vercel แทน ก็มี `vercel.json` ให้เช่นกัน (`vercel --prod` ในโฟลเดอร์ `web`, Framework: Other)

## ขั้นตอนที่ 4 · ตั้งค่างานในหลังบ้าน

เข้า `https://<เว็บของคุณ>/staff/login.html` → รหัส `ADMIN01` + PIN ที่ตั้งไว้

1. **ตั้งค่า & ทีมงาน**
   - จำนวนผู้ร่วมงานสูงสุด **400** · โควตาต่อซีรีส์ **80** (5 × 80 = 400)
   - เวลาขั้นต่ำระหว่างแสตมป์ **0 วินาที** = สแกนฐานถัดไปได้ทันที (ตั้งมากกว่า 0 ถ้าอยากกันสแกนรวดเดียว)
   - ข้อความประกาศผล เช่น "ประกาศผลบนเวที 19:00 น."
   - เพิ่มทีมงาน: รหัส + PIN 6 หลัก + บทบาท
     - **ของที่ระลึก** → เปิดหน้าสแกนมอบของ
     - **พิธีกร** → เปิดจอเวทีและกดสุ่ม
     - **ลงทะเบียน** → ดู/ค้นหารายชื่อ ช่วยลูกค้าที่จุดลงทะเบียน
     - **แอดมิน** → ทุกเมนู
2. **ผู้ร่วมงาน → นำเข้ารายชื่อล่วงหน้า (CSV)**: กด "ดาวน์โหลดไฟล์ตัวอย่าง" กรอกใน Excel แล้ว Save As **CSV UTF-8**
   คอลัมน์ `phone, name, email, company` (การ์ดซีรีส์ระบบสุ่มให้ตอนลงทะเบียนหน้างาน)
3. **ฐานกิจกรรม & QR**: ชื่อฐานตั้งไว้แล้ว (LUMENCRAFT · LIGHTING SOLUTION · KLIQ ROOM EXPERIENCE · KLIQ IKON MATCH · KLIQ CUSTOM COLORS · LiTon) แก้ได้ → กด **พิมพ์ QR ทั้งหมด** (ได้ QR จุดลงทะเบียน 1 ใบ + QR ฐาน 6 ใบ)
4. **Lucky Draw**: (ไม่บังคับ) **กำหนดลำดับการ์ดล่วงหน้า** เลือกว่าใบไหนเปิดเป็นใบที่ 1 (OUT) / ใบที่ 2 (IN = รางวัลที่ 3) / ใบที่ 3 (IN = รางวัลที่ 2) / ใบที่ 4 (OUT) / ใบที่ 5 (IN = รางวัลที่ 1) — ถ้าตั้งไว้ จอเวทีจะเล่นตามนี้แทนการสุ่ม (คนในการ์ดยังสุ่มจากวงล้อ) ต้องตั้งก่อนกด "เริ่มรอบชิง" · ตั้งชื่อรางวัลรอบชิง **4 ชิ้น**: ที่ 1 / ที่ 2 / ที่ 3 ชิ้นที่ 1 / ที่ 3 ชิ้นที่ 2 (ค่าเริ่มต้น: iPhone 18 Pro / iPad Gen 11 / หูฟังอินเอียร์ Beyerdynamic / หูฟังไร้สาย KEF Mu7 — รางวัลที่ 3 สองชิ้นหมุนวงล้อ 2 รอบจากการ์ดใบเดียวกัน ได้คนละคน) ใส่ **รูปของรางวัล** (คลิกกรอบรูป เลือกไฟล์ ระบบย่อให้เอง) และ **รายละเอียด** เช่น รุ่น/สี/มูลค่า — จะขึ้นบนจอเวที ป๊อปอัปผู้โชคดี และหน้า Passport ของลูกค้า และตั้ง **เวลาตัดยอด** · ที่หน้า ตั้งค่า ปรับ **เวลานับถอยหลังรอผู้โชคดีขึ้นเวที** (ค่าเริ่มต้น 30 วินาที) และตั้ง **ชื่อของที่ระลึก 2 แบบ** (ทั่วไป / พิเศษสำหรับคนเล่นครบทุกฐาน)

## ขั้นตอนที่ 5 · ซ้อมก่อนงาน แล้วล้างข้อมูล

1. ให้ทีม 3–5 คนลองลงทะเบียน สแกนครบ 6 ฐาน รับของ และพิธีกรลองสุ่มบนจอจริง
2. ทดสอบใน **LINE (สแกน QR ด้วย LINE)**, Safari บน iPhone และ Chrome บน Android
3. ซ้อมเสร็จ → Export ข้อมูลถ้าต้องการ → รัน `supabase/reset_event_data.sql` ใน SQL Editor เพื่อล้างข้อมูลซ้อม
   (QR ฐาน รางวัล และทีมงานยังอยู่ ไม่ต้องพิมพ์ใหม่)

| แอดมิน | `/admin/index.html` | ดูยอดสด ค้นรายชื่อ ตัดยอด ยกเลิกสิทธิ์ Export |

**กติกาที่ระบบบังคับให้อัตโนมัติ**
- 1 เบอร์ 1 สิทธิ์ ลงซ้ำด้วยเบอร์เดิม = กลับเข้าสิทธิ์เดิม (ใช้กรณีเปลี่ยนเครื่องหรือเปิดจากแอปอื่น)
- ครบ 400 คน หรือเลยเวลาตัดยอด → ปิดรับลงทะเบียนใหม่
- 1 ฐาน 1 แสตมป์ · สแกนฐานถัดไปได้ทันที (ถ้าตั้งเวลาขั้นต่ำไว้จะต้องรอ) · QR ปลอม/QR เก่าใช้ไม่ได้
- มือถือจำผู้ร่วมงานไว้ **1 วัน** (ต่ออายุทุกครั้งที่เปิด) ถ้าสแกน QR แล้วเปิดในแอป/เบราว์เซอร์คนละตัวกับที่ลงทะเบียน ระบบจะขอ **เบอร์โทร** เพื่อยืนยันตัวตน แล้วบันทึกแสตมป์ให้ทันที ไม่ต้องลงทะเบียนใหม่
- Walk-in ต้องกรอก **ชื่อ · นามสกุล · เบอร์โทร · บริษัท/ร้านค้า** (อีเมลไม่บังคับ) · ลงทะเบียนล่วงหน้ากรอกแค่เบอร์
- ของที่ระลึกมี 2 แบบ: **ทั่วไป** ทุกคนที่ลงทะเบียนรับได้ · **พิเศษ** สำหรับคนเล่นครบทุกฐาน · รับได้คนละครั้ง ถ้ารับแบบทั่วไปไปแล้วและมาเล่นจนครบทีหลัง เจ้าหน้าที่มอบแบบพิเศษเพิ่มได้ (ระบบบอกเอง) · บันทึกว่าใครมอบ เวลาใด แบบไหน
- การ์ดสุ่มให้ทุกคนตอนลงทะเบียน แต่ละซีรีส์ไม่เกินโควตา (400 คน = ซีรีส์ละ 80) เลขลุ้นโชคขึ้นต้นด้วยตัวอักษรของการ์ด (U / I / F / N / C)
- ลำดับเปิดการ์ดล็อกเป็น **OUT · IN · IN · OUT · IN** (ไม่มี OUT ติดกัน) ส่วน "ใบไหน" สุ่มและล็อกตั้งแต่กด "เริ่มรอบชิง" (ระบบเลือกลำดับที่การ์ด IN ทุกใบมีผู้ถือ) จากนั้นเปิดทีละใบว่าการ์ด IN ใบไหนเป็นรางวัลที่ 3 → 2 → 1 (สุ่มและล็อกไว้ตั้งแต่เริ่มเช่นกัน) ส่วนวงล้อสุ่มคนทีละรางวัลตอนกดหมุน (ผลสุ่มมาจากเซิร์ฟเวอร์ วงล้อบนจอแค่แสดงผล) กดซ้ำ/รีเฟรช/ปิดจอแล้วเปิดใหม่ เล่นต่อจากขั้นเดิมได้ ถ้ามีคนค้างอยู่ในป๊อปอัปก็เด้งกลับมาพร้อมเวลาที่เหลือ
- คนเดียวได้รางวัลเดียว · ผู้ที่วงล้อหยุดเห็นแบนเนอร์ "ขึ้นเวที" บนมือถือทันที ผู้ได้รางวัลเห็นผลบนมือถือทันที
- ผู้โชคดีไม่ขึ้นเวทีภายในเวลา (ค่าเริ่มต้น 30 วินาที ตั้งได้ที่ตั้งค่า) → พิธีกรกด **ไม่อยู่ · หมุนใหม่** ระบบตัดสิทธิ์คนนั้น (บันทึกไว้ในผลว่า "ไม่อยู่") แล้วหมุนใหม่จากผู้ถือการ์ดใบเดียวกัน
- ตรวจพบภายหลังว่าผู้ได้รางวัลไม่ตรงเงื่อนไข → แอดมินกด **ยกเลิกสิทธิ์** ที่หน้า Lucky Draw รางวัลนั้นจะเปิดให้หมุนวงล้อใหม่บนเวที หรือกด **สุ่มแทน** ทันทีถ้างานเลิกแล้ว

**ลำดับรอบชิงบนจอเวที (กด Space หรือปุ่มทีละครั้ง · F เต็มจอ · M ปิด/เปิดเสียง)**

| กด | บนจอ |
|---|---|
| เริ่มรอบชิง | การ์ด 5 ใบ UNO · IKON · FORMA · NOVA · CASA |
| เปิดการ์ดใบที่ 1–5 | ไฟวิ่งไล่การ์ดที่ยังไม่เปิด (เสียงรัวกลอง + ไต่ขึ้น) หยุดที่ 1 ใบ แล้ว **ค้าง 15 วินาที** ให้พิธีกรพูด "เข้ารอบหรือตกรอบ" (กด Space เปิดผลก่อนได้) → ใบที่ 1 และ 4 ตรา **OUT** (เสียงระเบิด) · ใบที่ 2, 3, 5 ตรา **IN** (เสียงเชียร์ + คอนเฟตตี) → ครบ 5 ใบ: แฟนแฟร์ ประกาศการ์ด 3 ใบที่เข้ารอบ |
| เปิดการ์ดรางวัลที่ 3 | ไฟวิ่งไล่ 3 ใบที่เข้ารอบ หยุดที่ 1 ใบ ค้าง 15 วิ → ตรา "รางวัลที่ 3" (ก่อนหมุนรางวัลที่ 2 และ 1 ก็เปิดการ์ดแบบเดียวกัน) |
| หมุนวงล้อ · รางวัลที่ 3 ชิ้นที่ 1 | วงล้อหมุน ~7 วิ หยุดที่เลขลุ้นโชค 1 ท่านจากผู้ถือการ์ด IN ใบแรก → ป๊อปอัปชื่อ + นับถอยหลัง |

## หลังจบงาน

1. แอดมิน → ผู้ร่วมงาน → **Export CSV** (มีรายชื่อ เบอร์ ซีรีส์ จำนวนฐาน การรับของ และรางวัล) ส่งมอบลูกค้า
2. ลบข้อมูลตามระยะเวลาใน `privacy.html` ด้วย `reset_event_data.sql` (เอา `--` หน้า `truncate preregistrations` ออกเพื่อลบรายชื่อล่วงหน้าด้วย)

## ก่อนใช้จริง ต้องแก้

- `web/privacy.html`: ใส่ชื่อบริษัทผู้ควบคุมข้อมูล ช่องทางติดต่อ และระยะเวลาเก็บ (ให้ฝ่ายกฎหมายลูกค้าตรวจ)
- ชื่อฐาน จำนวนรางวัลหูฟัง และเวลาตัดยอด: แก้ในหลังบ้านได้เลย ไม่ต้องแก้โค้ด

## ความปลอดภัย (สรุปสำหรับฝ่าย IT ลูกค้า)

- ทุกตารางเปิด Row Level Security และไม่มี policy → อ่าน/เขียนตรงผ่าน API ไม่ได้
- ทำงานผ่านฟังก์ชัน `security definer` ที่ตรวจสิทธิ์ทุกครั้ง; ฟังก์ชันภายในไม่เปิดให้ anon
- เจ้าหน้าที่ล็อกอินด้วย PIN (เก็บแบบ bcrypt) ผิด 5 ครั้งล็อก 10 นาที; session หมดอายุ 18 ชม.
- ผู้ร่วมงานถือ token สุ่ม 24 ไบต์ในเครื่อง; จอเวทีแสดงชื่อแบบปิดบางส่วน
- การลงทะเบียนใช้ advisory lock: ทดสอบลงทะเบียนพร้อมกัน 400 คน เลขลุ้นโชคไม่ซ้ำ โควตาไม่เกิน

## ผลการทดสอบก่อนส่งมอบ

- ฐานข้อมูล 120 กรณี ผ่านทั้งหมด (`tests/db_test.py`) รวมลงทะเบียนพร้อมกัน 400 คน สุ่มการ์ดไม่เกินโควตา รอบชิงครบทุกขั้น รวมกรณีไม่อยู่ในงานและหมุนใหม่
- เบราว์เซอร์ end-to-end 53 กรณี ผ่านทั้งหมด (`tests/e2e.py`): ลงทะเบียน → เปิดการ์ด → แสตมป์ → กู้สิทธิ์ด้วยเบอร์ → รับของ 2 แบบ → รอบชิงการ์ด 5→3 → เปิดการ์ดต่อรางวัล → วงล้อ → ไม่อยู่/หมุนใหม่ → ที่ 3·2·1 → ผู้ถูกเรียกและผู้ชนะเห็นผลบนมือถือ → ยกเลิกสิทธิ์และสุ่มแทน → Import/Export
- ทดสอบบนฐานข้อมูล PostgreSQL 16 จำลองบทบาทของ Supabase; ควรซ้อมบน Supabase จริงตามขั้นตอนที่ 5 อีกครั้ง
